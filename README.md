# AIRA Newsletter

> The one and only AI newsletter. Join us and get the best AI news, tools, and tutorials completely FREE!

Live on GitHub Pages: [https://deep-5.github.io/newsletter/](https://deep-5.github.io/newsletter/)

## 🚀 Features

- **Branding**: Full AIRA branding with custom lightning bolt logo.
- **Rich Formatted Articles**: Complete breakdown of latest AI breakthroughs, models, and robotics news.
- **Supabase Integration**: Real-time subscribers, comments, likes, and feedback polls database.
- **Search & Filters**: Instant modal search with `Ctrl+K` and category filters.
- **Responsive Layout**: Pixel-perfect design on mobile, tablet, and desktop.

## 🛠️ Local Development

```bash
# Start local server
npm start
# or
node server.js
```
Open [http://localhost:3000/](http://localhost:3000/) in your browser.

## 🌐 Deploy to GitHub Pages

1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)**
3. Save, and your site will be live at `https://deep-5.github.io/newsletter/` in 1 minute!
